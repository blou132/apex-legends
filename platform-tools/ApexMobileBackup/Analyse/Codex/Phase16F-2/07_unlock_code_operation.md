# Unlock-code operation

PotatoNV completed its documented code operation and produced a 16-character
code. The code was extracted without printing it and written only to an
ignored local Phase16F-2 file. Its format and ignore status were validated.

The full private PotatoNV log is also ignored and contains the only retained
raw serial, Board ID, saved-key, and code lines. Neither private file is staged
or committed.

```text
UNLOCK_CODE_OBTAINED = YES
UNLOCK_CODE_FORMAT_VALID = YES
UNLOCK_CODE_STORED_LOCAL_ONLY = YES
UNLOCK_CODE_PUBLISHED = NO
POTATONV_COMPLETED = YES
```
