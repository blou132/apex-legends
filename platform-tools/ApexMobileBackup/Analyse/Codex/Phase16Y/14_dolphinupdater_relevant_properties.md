# DolphinUpdater relevant properties

No DolphinUpdater-local property array is directly exposed by its recovered
class registration ABI. Reflection status and property names for offsets
`+0x40`, `+0x41`, `+0x42`, `+0x44`, `+0x45`, `+0x1f0`, and `+0x1f8` remain
unknown.

`DOLPHINUPDATER_REFLECTED_RELEVANT_PROPERTIES = UNKNOWN`

The absence of recoverable metadata is not used to infer that these native
fields are absent or non-reflected.
