# DolphinUpdater native functions

The standalone UClass registration supplies callback Ghidra `0x0a2aecd0`.
The target is executable-mapped but has no coherent decoded instruction stream
and is classified as `NON_DISASSEMBLED_OR_OPAQUE`.

Following or reconstructing that opaque callback would cross the explicit
GameProtector boundary. No native function table is therefore published.

`DOLPHINUPDATER_NATIVE_FUNCTION_COUNT = UNKNOWN`

`DOLPHINUPDATER_NATIVE_FUNCTIONS = NONE_RECOVERABLE_FROM_CLASS_REGISTRATION`
