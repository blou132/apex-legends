# Phase16T - Shutdown-anchored DolphinUpdater vtable group

Phase16T revalidated the exact Phase16S Shutdown cell and mapped only the
authorized local `.data.rel.ro` window. The cell belongs to an 83-entry
primary executable-pointer run followed by an Itanium-compatible secondary
header: offset-to-top `-0x28`, zero typeinfo, and an 11-entry secondary table.

The first secondary entry is exact ARM64 machine evidence for an adjustor
thunk: `sub x0, x0, #0x28; b Shutdown`. Together with the direct primary
Shutdown entry, this establishes a coherent primary/secondary group with
probable DolphinUpdater ownership. No second distinct known owner method or
new owner identifier was found, so identity is not promoted to confirmed.

The primary address point is probable because its expected offset-to-top cell
falls just before the authorized window; the secondary address point is
confirmed. Independent ELF instruction decoding and Ghidra's reference
manager found no exact code reference to either address point. Consequently,
no vptr store, constructor, related field initialization, allocation model,
callback relation, or new `+0x1f0` provenance route is proven.
