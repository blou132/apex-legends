# Phase16I - offline CVersionMgr callback trace

## Executive result

The exact Apex Mobile APK and OBBs were verified, installed on the rooted
sacrificial PRA-LX1, and launched with the whole phone offline. Package-only
AppData snapshots were captured before launch, after warm-up, and after the
trace. Raw data and runtime identifiers remain local-only.

Static revalidation proved `CVersionMgrImp::Init` at Ghidra `0x00576180`, ELF
VA `0x00476180`, `X0` as `this`, and `*X1` as the external callback stored at
manager `+0x18`. The strategy dispatch through callback vtable slot `+0x28`
was also reconfirmed.

The active launch selected exact native thread name `Thread-10`, correlated a
fresh offset-zero `libgcloud.so` mapping, and matched 16 runtime entry bytes to
the exact local ELF. One atomic breakpoint SET succeeded and read back the
expected Huawei control `0x000041e4`. No trap arrived within 90 seconds. The
breakpoint was explicitly disabled, ptrace detached, Apex was force-stopped,
and device/network health passed. No retry occurred.
