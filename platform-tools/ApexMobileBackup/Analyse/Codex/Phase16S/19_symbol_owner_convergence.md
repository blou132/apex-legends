# Symbol-owner convergence

No named Dolphin symbol is called from a proven pre-CheckUpdate
DolphinUpdater lifecycle method because no such method was recovered. The
gcloud interface RTTI/vtables validate the public provider ABI family but do
not identify the UE4 owner object or its `+0x1f0` assignment.

`DOLPHIN_SYMBOL_OWNER_CONVERGENCE = NONE`

The symbol inventory therefore supplies no alternate provenance route to the
persistent interface.
