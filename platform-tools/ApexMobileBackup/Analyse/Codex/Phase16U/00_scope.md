# Phase16U scope

Phase16U was PC-only, static, and read-only. It tested only exact aliases,
VTT/construction-vtable forms, literal or data indirection, and target-page
address construction for the proven DolphinUpdater vtable group.

No phone, ADB, Apex process, ptrace, breakpoint, AppData, GameProtector,
network, binary modification, generic constructor scan, or writable Ghidra
operation was used.
