# Persistent storage

Two independent callback lifecycle methods load, null-test, and pass the same
exact field to proven owner continuations. This promotes the field location,
not its missing writer, as a persistent storage anchor.

```text
DOLPHINUPDATER_PERSISTENT_STORAGE = DOLPHIN_CALLBACK_SUBOBJECT_PLUS_0x08
DOLPHINUPDATER_STORAGE_CONFIDENCE = CONFIRMED
```

The stored value's DolphinUpdater semantic identity remains probable because
this field did not converge with a CheckUpdate or externally called Shutdown
storage source.
