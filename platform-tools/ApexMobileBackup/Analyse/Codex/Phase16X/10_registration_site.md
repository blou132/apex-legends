# Registration site

No source-registry mutation survives the exact-key and same-collection
filters. The registration site is therefore not statically recoverable from
the authorized anchor.

```text
SELECTED_ENTRY_REGISTRATION_SITE = UNKNOWN
SELECTED_ENTRY_REGISTRATION_FUNCTION = UNKNOWN
SELECTED_ENTRY_REGISTRATION_REACHABLE = NO
SELECTOR_KEY_INSERTION_PROVEN = NO
SELECTOR_KEY_INSERTION_SITE = UNKNOWN
```
