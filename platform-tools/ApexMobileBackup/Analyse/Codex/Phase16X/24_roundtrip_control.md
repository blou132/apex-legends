# Roundtrip control

A registration/lookup roundtrip cannot be validated because the registration
site is not resolved. The derived cache path is not a substitute for source
registry insertion.

No neighboring-key control was used after the exact-key stop condition was
met.

```text
COLLECTION_REGISTRATION_LOOKUP_ROUNDTRIP_VALID = UNKNOWN
COLLECTION_CONTROL_VALID = NOT_RUN_NO_REGISTRATION_SITE
```
