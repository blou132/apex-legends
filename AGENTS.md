# Agent instructions

This repository is an analysis workspace for Apex Legends Mobile. Work only from evidence already present in the repository or newly generated by an explicitly requested analysis step.

Read `CHATGPT_CONTEXT.md` before investigating a target. Treat `Phase3/Phase3C/` as authoritative for address mapping and corrected function candidates. Phase3B is historical evidence and contains conclusions invalidated by the missing image-base adjustment.

Use these confidence labels consistently:

- `CONFIRMED`: directly supported by an artifact in the repository.
- `PROBABLE`: supported by several indicators but missing a complete code or runtime path.
- `UNKNOWN`: not demonstrated by current evidence.
- `INVALIDATED`: contradicted by newer evidence.

Never present a hostname, IP, port, native function, RPC, event handler, or call path as confirmed without citing the exact report or JSON evidence. Always distinguish ELF virtual addresses from Ghidra addresses. The verified mapping is:

```text
GHIDRA_ADDRESS = ELF_VIRTUAL_ADDRESS + 0x100000
```

Do not add APK, OBB, PAK, SO, DLL, EXE, media files, local Ghidra databases, Java class files, or process IDs to Git. Text reports, scripts, JSON exports, and execution logs are intended to remain available to remote AI assistants.
